# tourism-app

Tourism company full-stack app with **saved destinations** and **rich place info**.

- Backend: Fastify → http://localhost:3000
- Frontend: React + Vite → http://localhost:5173

## Features

- 🌍 Browse tours by destination
- 📸 Multi-image galleries per destination
- 📖 Rich info: history, culture, best time, cuisine, tips
- ❤️ Save / unsave destinations (persisted)
- 🎫 Book tours with live price calc

## Setup

```bash
pnpm install
pnpm dev
```
